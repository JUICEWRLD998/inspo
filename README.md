# Inspo

Customers send a picture of the cake they want. The bakery's WhatsApp replies with a real price in about 20
seconds, priced from the maker's own rate card, and the order lands on her bake calendar once she approves.

**Status: NOT LIVE.** In development for the Base44 Challenge on Contra (October 2026). The full README is written
in phase P1 of `implementation.md`.

Built on Base44: an app agent on WhatsApp, entities, backend functions and automations.
